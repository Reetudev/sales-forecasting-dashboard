# PredictIQ - AI-Powered Revenue Forecasting & Business Intelligence Dashboard

## Overview

PredictIQ is an AI-powered business intelligence dashboard that analyzes historical sales data and forecasts future revenue trends.

## Features

- Revenue Forecasting
- AI Business Insights
- KPI Dashboard
- Sales Trend Analysis
- Store Performance Analytics
- Product Analytics
- Download Forecast Reports

## Technologies

- Python
- Pandas
- NumPy
- Plotly
- Scikit-Learn
- Streamlit
- Joblib
